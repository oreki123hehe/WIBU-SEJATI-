# Wibu Sejati — UI Contract

UI target is fixed from the beginning so backend iteration does not repeatedly redesign the application.

## Bottom navigation
1. Home
2. Explore
3. Watchlist
4. History

## Home
- App branding
- Continue watching
- Latest episodes
- Popular anime
- Recently added

## Explore
- Search
- Genre
- Year
- Status
- Sort

## Detail
- Poster
- Title
- Alternative titles
- Synopsis
- Genres
- Year/status
- Watch button
- Episode list
- Watchlist toggle

## Player
- Video area
- Episode title/number
- Previous/next episode
- Playback state
- Source availability state

## Notifications
New episode notification opens directly to the relevant anime episode.

## Design rule
New backend features may add data, but the main navigation and core screen hierarchy remain stable.
